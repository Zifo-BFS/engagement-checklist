# Engagement Checklist

Onboarding checklist for Salesforce assignments. Signs in with the company
Microsoft account and uses Microsoft 365 (Outlook, To Do, OneDrive/SharePoint).

- Edit `js/config.js` for tenant, permissions, storage and kickoff rule.
- Edit `js/templates.js` for checklists and email text.
- No client data is stored in this repository. All data stays in Microsoft 365.
- Libraries (MSAL 3.28.1, SheetJS 0.18.5) load from jsDelivr with integrity checks.
